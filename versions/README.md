# Versions

Every stage of Shan Shui Notebook, oldest first. Each file is a complete, standalone page; open it in a browser to see that stage. Most accept `?seed=` like the current version.

| File | What changed |
| --- | --- |
| [v00-stitched-first-draft.html](v00-stitched-first-draft.html) | First draft. The original ink landscape on a notebook page whose rules and margin are stitched in thread; small boats and birds sketched in pencil. |
| [v01.html](v01.html) | The rules turn into the landscape: plain rules first, then bent toward the mountain outlines while the drawing fades in. Mountains and water in notebook blue, trees and buildings in pencil. |
| [v02.html](v02.html) | Rules land on the outlines that are actually drawn, stitched while they move; the lower rules carry on as water; the red margin bows near ridges. |
| [v03.html](v03.html) | Clean, solid rules throughout; no pencil until the transition ends; the original washes for distant ranges. |
| [v04.html](v04.html) | Trees back to the original inky blots; taller mountains; a longer transition. |
| [v05.html](v05.html) | Transition back to pages 2–4, slightly smaller mountains, and section comments throughout the code. |
| [v06.html](v06.html) | Each rule runs straight until an outline rises through it, then becomes that outline. Mountains back to the original size. |
| [v07.html](v07.html) | Rules ease into lines of their own in a slow, shared wave (after Candace Hicks) instead of snapping. |
| [v08.html](v08.html) | Rules choose where to join the drawing, keeping their order, then blend into it across page 3. |
| [v09.html](v09.html) | Depth: a rule ends at the edge of the first land standing in front of it. Tested on five random seeds with a new transition check: no crossings, no lines through land. |
| [v10.html](v10.html) | After the transition, water lines turn into rippling ink strokes. |
| [v11.html](v11.html) | High rules rise into distant ranges, and the very highest become mist, instead of fading out. |
| [v12.html](v12.html) | Drawn as page tiles that slide, with a smooth continuous auto-scroll. |
| [v13.html](v13.html) | Ready for the web: fits any window or frame, embed and URL options, license notice. |
| [v14.html](v14.html) | The landscape is generated in a background worker. |
| [v15.html](v15.html) | The worker also paints each page, so the page itself does no rendering. Same as `../index.html` at the time it was saved. |
